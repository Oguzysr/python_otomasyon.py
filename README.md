# Kütüphane Yönetim Sistemi

## Proje Hakkında

Python ile geliştirilen bu proje, kitap ve dergi kayıtlarının yönetilmesini sağlayan konsol tabanlı bir kütüphane otomasyonudur.

## Özellikler

- Kitap ekleme, silme, güncelleme ve listeleme
- Dergi ekleme, silme, güncelleme ve listeleme
- Kayıt numarası kontrolü
- Menü üzerinden işlem yapabilme

## Kullanılan Teknolojiler

- Python 3
- Nesne Yönelimli Programlama (OOP)
- ABC modülü

## Kullanılan Konular

- Sınıflar ve nesneler
- Kalıtım
- Soyut sınıflar ve metotlar
- Kapsülleme
- Listeler ve döngüler
- Koşullu ifadeler

## Çalıştırma

```bash
python main.py
```

## Veri Saklama

Kitap ve dergi kayıtları Python listelerinde tutulur. Program kapatıldığında kayıtlar silinir.
